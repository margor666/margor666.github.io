Privacy Policy

Last updated: November 2, 2026

About the Application

EfEh Server Backup is a private, self-managed backup system for a local Ubuntu server.

Google Drive Access

Google Drive access is used to upload, download, verify and manage encrypted server backup files.

Data Storage and Security

Backup files are encrypted locally using rclone crypt before being uploaded to Google Drive.

Data Sharing

Google user data is not sold or shared for advertising purposes. The application is not offered as a public service.

Data Retention

Cloud backups are retained according to the server's configured retention policy and may be deleted by the operator.

Contact

For privacy questions, contact the application operator using the support email shown on the Google OAuth consent screen.
